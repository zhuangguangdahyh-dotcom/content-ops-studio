# Contributing

Read `AGENTS.md`, the relevant documents, and accepted ADRs before editing core behavior. Use an ExecPlan when `PLANS.md` requires one. Keep examples fictional, add tests for deterministic logic, document Schema migrations, and run `pnpm check` before review.

Do not add a production dependency without explaining why it is necessary. Do not add customer data, secrets, hooks, production MCP wiring, or undocumented external side effects.
