The publish-title length must be calculated by deterministic code. V1 counts Unicode code points. Version 1.1.0 also separates publish title, cover conversion copy, and page-one content copy. For lead-generation accounts, the cover requires specific Subject, Audience, Painpoint or Value context, true-size 310×414 and 186×248 thumbnail QA, click clarity of at least 85, and semantic relevance of at least 80. Passing these checks never grants Operator approval.

The pack does not make professional industry judgments and intentionally avoids an untested library of "viral" rules. Industry and Project context still determine what scene, subject, claim, and visual direction are appropriate.
