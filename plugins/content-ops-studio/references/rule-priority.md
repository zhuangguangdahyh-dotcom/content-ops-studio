# Rule priority

Apply rules in this order:

1. Safety, compliance, factual accuracy, data protection, and tool permissions.
2. Current explicit Operator request.
3. Confirmed long-term project rules.
4. Platform pack.
5. Industry pack.
6. Plugin defaults.

The Current Run may override ordinary defaults but never the first layer. A current instruction does not automatically become a long-term rule. Project Learning must preserve original wording and require explicit confirmation before project-wide activation.
