# Feedback and learning policy

Classify feedback as Quality Defect, Production Feedback, Visual Preference or Project/Domain Constraint. Default to the smallest scope. Only explicit preferences and constraints may become Rule Candidates; Production Feedback remains current-work-only unless the Operator separately classifies a reusable preference or constraint. Eligible candidates still require explicit confirmation. Confirmation creates a new Project Visual Profile version and may move COLD_START to LEARNING or a sufficiently proven LEARNING Profile to MATURE. G4/G5 do not automatically create long-term preferences. Current-set overrides do not edit the Profile. Retain historic Profile/rule bindings and support supersede, disable, revoke and forget without deleting audit history.
