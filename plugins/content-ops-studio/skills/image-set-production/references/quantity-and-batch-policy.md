# Quantity and batch policy

Default final count is 4–8, commonly 5–6, but approved page count wins. Track final pages, distinct source backgrounds, direction candidates, formal candidates, attempts, failures and retained history separately. After G4, create the Image Set Production Strategy before producing remaining pages. For high consistency risk, internally test two representative pages before continuing. Rework only failed pages.

Page count is not a license to repeat assets. For an image-dependent set, the plan declares how many pages require distinct backgrounds and must supply at least that many unique verified source checksums. A page using Pure Typography or a precise Programmatic Graphic declares `NO_RASTER_BACKGROUND`; evidence reuse must be explicit and materially justified.
