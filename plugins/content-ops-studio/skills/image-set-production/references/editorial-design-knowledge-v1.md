# Editorial Design Knowledge V1

Use `EDITORIAL_DESIGN_KNOWLEDGE_V1 / 1.0.0` as a lower-precedence knowledge layer, never as a named-magazine style or candidate template. Runtime browsing is forbidden; source provenance is the committed manifest.

Resolve one page intent: `COVER_ENTRY`, `CONTENT_EDITORIAL`, `EVIDENCE_PAGE`, `DIAGNOSTIC_PAGE`, `SUMMARY_PAGE`, or `CTA_PAGE`. Cover Entry uses compressed information, a clear primary hook and one-second stopping power. Content pages use reading, evidence progression and group pacing. Never copy scale or density rules between them.

For `COVER_ENTRY`, choose one suitable Attention Mode from `TYPE_DOMINANT`, `IMAGE_DOMINANT`, `TYPE_IMAGE_COLLISION`, `CROP_DOMINANT`, `COLOR_DOMINANT`, `EVIDENCE_DOMINANT`, `CONTRAST_DOMINANT`, or `HYBRID_ATTENTION`. Record primary/secondary/tertiary attention, verbal and visual hooks, mass, scale, crop, grid/break, negative space, image/type relation, color dimensions and quantity, silhouette, compression, motif, rationale and risks.

Run gates in order: Copy and font resolution → Spatial Integrity → Breathing Room → Typography as Form → grayscale structure → visual mass → Cover Attention → existing thumbnail/click/semantic/Painpoint/image-quality gates → actual-pixel Operator comparison. Color never rescues weak grayscale structure. One clear primary mass is mandatory. Actual 186×248 inspection is mandatory.

Cold-start candidates differ across at least three of copy strategy, motif, attention mode, composition, color, image, crop and type scale. Do not learn any preference or create Style Lock from calibration or scores.
