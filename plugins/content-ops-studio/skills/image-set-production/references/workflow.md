# Workflow

Context → Dynamic Visual Strategy + confidence/ambiguity → page asset routing → maturity-derived direction plan → Host/Renderer execution → durable candidate submission when required → image QA → show previews → `AWAITING_USER_SELECTION`. A compatible MATURE Profile may go directly to one formal first page. After selection when required: selection artifact → Visual Plan revision → formal first page → verification → G4. After G4: Style Lock → Image Set Production Strategy → distinct-background/shot production → single-page QA → Image Set Continuity QA + contact-sheet review → G5. Never collapse these gates.

The full-set strategy is created before any remaining-page generation. It binds one visual motif and continuity anchors, then assigns each page one duty, semantic responsibility, source-background policy, shot signature, composition family and explicit difference from the previous page. Do not begin the batch when a scene/editorial series plans the same raster master for multiple pages under `DISTINCT_BACKGROUND_REQUIRED`.

For every formal page, the production sequence is fixed: audit deterministic inputs and stable asset ordering → create the pinned render context and seed → wait for font/image readiness and stable geometry → run real-font Text Layout Preflight → apply at most the bounded ordered layout recovery → capture the candidate and replay in fresh contexts → run Copy/Graphic Separation and final-raster contrast in an isolated QA context → evaluate all formal promotion gates → write the PNG to the formal path only on full PASS. Any failed candidate stays under the attempt path with its checksum and reason.

The layout recovery order is semantic line-break repair, text-region expansion, local composition movement, bounded font reduction above the declared minimum, line-height adjustment, tracking adjustment, then page-composition revision. It never changes approved copy. Final-raster contrast recovery may change only text region, foreground color, local value, graphic position, crop or local composition while preserving the visual-system key.
