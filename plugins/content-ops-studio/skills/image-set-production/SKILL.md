# Purpose

Turn G3-approved copy and an executable Visual Plan into traceable visual assets without changing copy, inventing evidence, hiding provenance, or bypassing Operator approvals.

# Required preflight

Load Image Production Context, exact Content/Copy/Cover Copy/Visual versions, Project Profile, Subject, Audience, Platform Pack, Industry Visual Pack and overlays, Project Visual Profile, confirmed global preferences, current Painpoint and Content Package, account goal, cover objective and conversion strategy, page roles, current Operator request, authorized Project/evidence assets, approved/rejected references, G4/G5 history, Feedback Events, Confirmed Rules, current Style Lock, Host ImageGen/Renderer capabilities, constraints and saved attempts. Never infer project state from chat.

# Workflow

Use the bundled `content-ops` MCP tools for context, routing, local artifacts, quality, feedback and rules. First synthesize a Dynamic Visual Strategy for this content. Visual Mode is a primitive and Industry Pack is a prior/risk boundary; neither is a finished style. Current explicit Operator requirements outrank compatible Profile defaults. Per-content semantics, page role, evidence need and authorized assets make the final route.

`COLD_START` plans two or three materially different directions; `LEARNING` plans one or two; compatible `MATURE` Profiles default to one formal first-page direction; `REVIEW_REQUIRED` blocks reuse and requests review. Candidate directions are dynamically derived and may share a channel when their subjects, compositions and visual arguments are materially different. Never reserve A/B/C for AI, Pure Typography and Mixed templates.

Read `references/universal-visual-baseline-policy.md`. When no higher-precedence typography or composition rule exists, apply `UVDPV-1` and `TDPV-1` as fallback only. Verify the actual font and weight in the Renderer; never synthesize bold, download a font or silently fall back to PingFang. Important images need at least two real spatial relationships. Every image declares its semantic responsibility and image-text anchor. Before Visual Quality scoring, require actual-geometry and actual-pixel `TYPOGRAPHY_SPATIAL_INTEGRITY` plus relative `TYPOGRAPHIC_BREATHING_ROOM`; a score cannot override either block. Two- or three-direction sets must pass Candidate Set Visual Diversity at 85 or higher with zero hard blocks.

Read `references/editorial-design-knowledge-v1.md` for Cover and editorial work. Resolve `page_design_intent` before composition. `COVER_ENTRY` requires one candidate-specific Cover Attention Mode and a strict Cover Attention Plan; inner pages must not inherit cover-scale attention mechanics. After Typography Spatial Integrity and Breathing Room, require typography-as-form, grayscale-first color and visual-mass evidence before `COVER_ATTENTION_DOMINANCE`. Inspect the actual 186×248 PNG for one-second impact. Passing never selects a candidate.

Invoke the Host's installed `$imagegen` capability once per generated direction, then immediately materialize each returned file into Project Home through the Host bridge. Do not request an API key. Do not retain a temporary conversation URL.

Use the six channels `PROJECT_ASSET`, `AI_GENERATED_VISUAL`, `PROGRAMMATIC_GRAPHIC`, `EVIDENCE_ASSET`, `PURE_TYPOGRAPHY`, and `MIXED_ASSET`. Visual Mode is independent of channel. Route safety, authenticity, authorization and evidence before aesthetics. Production never falls back to Mock.

All formal information text is rendered deterministically. Generated backgrounds are text-free. Direction candidates are preview assets only: they do not create a First Page Version, G4, Style Lock, formal Feishu visual write, or delivery asset. Show the real previews and stop at `AWAITING_USER_SELECTION`; never choose for the Operator.

Before any candidate can become a formal asset, apply `DETERMINISTIC_RENDER_CONTEXT_V1`, wait for fonts, embedded images and consecutive DOM geometry samples, and capture the formal PNG and replay from two fresh equivalent browser contexts. QA-only DOM changes, including hiding text for background analysis, run in a third isolated context. Run real-font Text Layout Preflight before screenshot promotion; overflow, clipping, collision, unsafe bounds, insufficient breathing room, orphan glyphs or punctuation, protected semantic-unit splits and font shrink below the declared minimum are hard blocks. Raster contrast is measured on the final composed geometry from a text-hidden QA raster. Decorative sequence markers are graphic layers and are excluded from Copy Fidelity only when they add no unapproved meaning. A failed attempt remains an attempt and is never written to the formal asset path.

For lead-generation covers, generate real full-size previews plus actual Renderer outputs at 310×414 and 186×248. The primary hook must remain the first focus, communicate one click message, and visibly connect to the Audience, Painpoint, Value, Risk, or Decision. Apply the 100-point Click Clarity model with an 85 threshold and the 100-point Semantic Relevance model with an 80 threshold. `DECORATIVE_ONLY` is blocked; weak or rejected abstract metaphors are blocked. Passing mechanical checks or scores never grants aesthetic approval.

For `PAINPOINT_FIRST`, `RISK_FIRST` and `QUESTION_FIRST`, also require Painpoint–Scene Congruence at 85 or higher. A merely industry-related or perfect-success scene cannot evidence a failure claim without an explicit contrast. Diagnostic markers must point to visible, explained evidence. Resolve locale from the Operator, Project region and Audience context; ask one consequential region question only when unknown locale materially changes the visible scene.

After explicit direction selection, preserve history, create the separate Visual Plan revision, and produce one formal first page. Verify the PNG and five-layer quality, show it, then stop at G4. Only a checksum-bound explicit G4 APPROVE may create a three-part Style Lock. Remaining pages require that active Style Lock; G5 remains separate.

Before producing a formal set, read `references/set-narrative-continuity-policy.md` and create an Image Set Production Strategy. One set must share one visual motif and one visual-system key, but consistency never means repeating one raster background under different crops. For image-dependent pages, plan distinct source backgrounds, materially different shots or spatial nodes, and page-specific semantic responsibilities. Page 1 owns click entry; middle pages own value delivery; the final page owns useful summary and conversion. A different layout cannot disguise duplicate source pixels, same-axis near duplicates or a repeated page responsibility.

# Quality and learning

Apply authenticity/integrity, mechanical, visual, mode/project-fit, and Operator-aesthetic layers. Hard blocks override scores. Candidates require 75; formal assets require 85 and core ratings of at least 3. Scores never approve G4 or G5. Group QA checks consistency and real difference at contact-sheet level. Formal full sets must also pass Image Set Continuity evidence for page-duty fulfillment, shared visual-system continuity, distinct-background compliance, shot/composition diversity, narrative progression and mobile readability. The legacy candidate-oriented Group Quality report alone is insufficient for a formal full set.

Record feedback at minimum scope. Quality defects and system failures never enter aesthetic learning. A long-term rule requires Feedback Event → Rule Candidate → explicit Operator confirmation. Support versioning, supersede, disable, and forget without deleting audit history.

# History and project isolation

Never turn one Content's selected direction, G4/G5 result or production feedback into a Project, Industry or Global preference. Preserve every historic Plan, Profile, Candidate, asset, checksum, rule version and gate binding. Project learning changes only the versioned Project Visual Profile; it never edits Industry Packs or global preferences. A current-set override applies to that Run only.
