# Examples

- Three public sources support five useful painpoints although 30 were requested → return five, record source/coverage limitations, do not create 25 hypotheses.
- Two independent reports support the same decision barrier → B can be valid if the sources are genuinely independent.
- One public comment suggests an anxiety → C, not a market-wide fact.
- The Operator explicitly asks to retain an unverified idea → D only if the Plan allows it; defer it, mark limitations, never CORE or high promotion.
- G2 decisions are three approve, one revise and one reject → persist five item decisions, then one version-matched generic G2 approval; update each row without deleting any item.
