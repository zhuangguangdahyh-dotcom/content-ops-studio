# Tool policy

Use only the eight bounded `content_ops_*` research tools plus existing project/status/approval tools. Search and page access remain host-native; submit their bounded results. The MCP server exposes no general browser, fetch, search, shell, file or raw Feishu operation. Finalization is the only initial remote research write and requires explicit confirmation/idempotency binding. Read tools do not mutate. G2 update requires a prior review artifact and explicit approval.
