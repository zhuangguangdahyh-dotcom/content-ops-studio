# Editorial Design Knowledge and Cover Attention

## Position and precedence

`EDITORIAL_DESIGN_KNOWLEDGE_V1` (`1.0.0`) is a versioned knowledge layer of principles, grammar and quality heuristics. It is not an Industry Visual Pack, Project Visual Profile, Style Lock, candidate template or runtime web-research step. Safety, the current Operator request, approved Style Lock, Project Profile, confirmed preferences, current Painpoint/Content/evidence/assets, Industry/Platform Packs and the Universal Visual Baseline continue to outrank it.

## Source provenance

The strict source manifest records public AIGA, JAGDA, Cooper Hewitt/Smithsonian, Pentagram, Adobe, Yale University Press, The Gentlewoman and Fantastic Man material with verification dates, derived principles and limitations. Only concise original summaries are stored; no long copyrighted passages are copied. Runtime image production never browses these sources.

## Principles and grammar

The ten principles are System Before Style, Consistency Is System Not Sameness, Hierarchy Before Decoration, Form Before Color, Negative Space Is Active, Type Is Visual Form, Image and Type Must Dialogue, Controlled Tension, Grid Is Scaffold Not Cage and Restraint Is Editing. They constrain reasoning without prescribing a named publication style.

The grammar covers hierarchy, scale contrast, visual mass, asymmetric balance, active negative space, grid discipline and controlled breaks, crop and edge tension, type and line-break shape, image/type dialogue, value and saturation contrast, color quantity, information compression, distinctive silhouette and editorial pacing.

## Page-design intent

Every page can declare `COVER_ENTRY`, `CONTENT_EDITORIAL`, `EVIDENCE_PAGE`, `DIAGNOSTIC_PAGE`, `SUMMARY_PAGE` or `CTA_PAGE`. A Cover compresses information and establishes one fast entry; an inner page prioritizes reading, evidence progression and group consistency. Cover scale does not become an inner-page rule, and inner-page density does not become a Cover rule.

## Cover Attention Plan and gate

The modes `TYPE_DOMINANT`, `IMAGE_DOMINANT`, `TYPE_IMAGE_COLLISION`, `CROP_DOMINANT`, `COLOR_DOMINANT`, `EVIDENCE_DOMINANT`, `CONTRAST_DOMINANT` and `HYBRID_ATTENTION` are strategy primitives. A strict plan records primary/secondary/tertiary attention, hooks, visual mass, scale, crop, grid and grid break, negative space, image/type relation, color dimensions and quantity, silhouette, compression, motif, rationale and risks.

`COVER_ATTENTION_DOMINANCE` runs after Typography Spatial Integrity and Typography Breathing Room and before G4. It evaluates hook dominance, one-second recognition, actual 186×248 stopping power, visual-mass hierarchy, information compression, silhouette, contrast, controlled tension, promise alignment and Audience signal. Thumbnail QA asks whether the cover is readable; this gate asks whether it is attention-worthy. Passing still requires Operator selection.

## Visual mass, color and type

Visual mass combines measured area, weight, value/saturation contrast, position, isolation, scale and subject strength, then reports primary, secondary and tertiary masses. `COVER_ENTRY` requires one clearly dominant primary.

Color is evaluated after grayscale structure. Hue, value, saturation, temperature and quantity are contextual; there is no fixed palette or universal accent percentage. Weak grayscale structure returns `COLOR_NOT_ALLOWED_TO_RESCUE_STRUCTURE`.

Typography-as-form evaluates line-break shape, text-block shape, edge and scale relations, vertical rhythm and mass distribution. It cannot bypass copy fidelity, font resolution, overflow, clipping, Spatial Integrity or Breathing Room.

## Learning and future Style Lock

Project Visual Profile exposes explicit, versionable and revocable Cover Attention preference fields, but no calibration result or single G4 event mutates them. A future approved Style Lock separates `cover_locked_rules`, `group_shared_rules` and `content_page_allowed_variations`; this phase creates none.
