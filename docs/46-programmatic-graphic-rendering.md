# Programmatic Graphic rendering

`PROGRAMMATIC_GRAPHIC` means deterministic, local, text-free geometry. It is not AI image generation. The Phase 4B Cover uses only allowlisted frames, lines, number markers, brackets and accent blocks compiled by `ProgrammaticGraphicCompiler`.

The background must not contain formal Chinese copy, people, certificates, official marks, logos, screenshots, UI replicas or remote assets. Formal title, body and page number remain separate Renderer Text Layers sourced exactly from the approved Handoff.

Arbitrary HTML, CSS, JavaScript, SVG primitives, URLs and event attributes are rejected. The compiled asset is stored under the external Project Home with a SHA-256 and a `PROGRAMMATIC_GRAPHIC` Generation Manifest whose provider is `LOCAL_DETERMINISTIC` and whose model is `NOT_APPLICABLE`.
