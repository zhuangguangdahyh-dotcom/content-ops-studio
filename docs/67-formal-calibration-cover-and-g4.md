# Formal calibration Cover and Calibration G4

Phase 4B-R.2.4 turns an explicitly selected calibration direction into a newly produced formal Cover. A direction candidate is reference evidence only: its file path and checksum may never be reused as a formal asset.

## Formal pipeline

The pipeline is ordered as follows:

1. Record the Operator's calibration-only direction selection.
2. Re-run visual strategy, Cover attention planning and asset routing.
3. Generate or select a valid text-free scene asset.
4. Let Renderer own every formal Chinese glyph.
5. Run mechanical, spatial, breathing-room, thumbnail, semantic, scene, editorial, integration, attention, mass, grayscale, color, typography-form and image-quality checks.
6. Inspect actual 1242×1660, 310×414 and 186×248 pixels.
7. Require byte-identical same-environment replay.
8. Create a checksum-bound pending Calibration G4 request.

The current calibration uses `CV-1 / CV-1 / VV-1 / FPV-1`. These versions belong only to `CAL-COMMERCIAL-SPACE-001` and do not alter C-0001.

## Text-background decision order

Readable text must be achieved in this order: natural negative space; image crop or composition; text-region adjustment; local value adjustment; restrained gradient or mask; visible panel. The selected formal composition uses natural sky and facade space and contains no default panel or gradient mask.

## Font evidence

The formal title resolves to system `Songti SC` weight 700. The Supporting Signal resolves to `Songti SC` weight 400. No font is downloaded, copied or embedded, and no synthetic outline is used. Chromium platform-font inspection is retained with the Renderer report.

## Calibration G4 boundary

Passing scores create eligibility, not approval. The review request remains `CALIBRATION_G4 / AWAITING_USER_APPROVAL / PENDING_OPERATOR`. There is no Approval Event, formal Style Lock, remaining page, Feishu write, Project Visual Profile mutation, Industry Pack mutation or Global Preference mutation.

The Style Lock Preview is read-only. It separates Cover-only rules, group-shared rules and permitted content-page variation so Cover-scale typography is never mechanically copied to inner pages.

## Historical integrity

The harness hashes candidate A–K and the current C-0001 FPV-2 before and after formal production. Any mismatch blocks G4. A pre-presentation internal attempt that resolved supporting text to PingFang SC was preserved, explicitly marked superseded and never assigned as the Operator-facing formal version.
