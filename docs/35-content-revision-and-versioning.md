# Content Revision and Versioning

Revision is non-destructive. Supported scopes include title only, body only, CTA only, page copy, structure, core viewpoint and full rewrite. The Revision Plan states the requested scope, affected fields/pages, version increment and invalidated approval.

Copy-only edits increment Copy Version; structural or viewpoint changes increment Content Version and establish a new Copy Version according to the plan. Prior local artifacts and prior G3 evidence remain available. No approved version is overwritten, and an old approval cannot authorize a new version.

The revision planner is dry-run in Phase 3B. A revised package must repeat Claim, duplication and quality validation and must obtain a new explicit G3 decision before Visual Planning eligibility.

Visual Plan Version is independent. Direction/color/typography/layout/asset changes increment only `VV-N` and retain prior plans. Copy or page-count changes never use Visual Revision; they follow this Content revision path and a new G3.
