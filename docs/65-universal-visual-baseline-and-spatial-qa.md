# Universal Visual Baseline and spatial QA

## Position

`UVDPV-1` is a fallback-only cold-start baseline. It is not a style, template, Project Profile or Industry Pack. The decision order is safety/authenticity/authorization; current Operator request; active Style Lock; Project Visual Profile; confirmed Global User Preference; current Content/Painpoint/evidence/assets; Industry Pack/Overlay; Platform Pack; then Universal Default.

## Typography

`TDPV-1` prefers a Renderer-verified modern Chinese serif only when no higher rule supplies a font. Title uses a real available 700/800 or the heaviest formal weight; subtitle uses Regular/Medium without default bold; body uses Regular. Synthetic bold, font copying/downloading and silent PingFang fallback are forbidden. The Renderer records requested and resolved family/weight. Unavailable families fail closed.

`TYPOGRAPHY_SPATIAL_INTEGRITY` and `TYPOGRAPHIC_BREATHING_ROOM` run before Visual Quality scoring. They consume real Playwright bounding boxes and computed typography values, then require a separate actual-pixel visual inspection. A non-overlap calculation alone cannot prove that text, graphics and the focal scene have enough separation.

The hard gate blocks text/text overlap, text/graphic occlusion, visual-region collision, insufficient relative padding, line/glyph collision, forced tracking, orphan-character breaks, competing primary text and density-forced compression. Breathing room is measured relative to the resolved line height and composition; it is not a fixed-pixel house style. If approved copy cannot fit faithfully, the workflow returns to Cover Copy Revision or Page Composition Revision instead of silently compressing the type.

## Composition

An important image normally needs at least two real spatial relationships. Supported Composition Families are dynamic primitives, not fixed candidate layouts. A clean photo plus mechanically placed text does not pass by cleanliness alone. Image, subject, edge, depth, light, negative space and text must establish an explainable reading path.

## Image-text and semantic relation

Every image declares a semantic responsibility. Text must cooperate with visible evidence and may not obscure it. A Painpoint-, Risk- or Question-first cover requires direct problem evidence, an Audience-recognition scene or a valid contrast. Industry relevance alone is insufficient. Diagnostic markers must point to visible and explained regions.

## Diversity and locale

A two- or three-candidate set varies composition family, text region, shot scale/viewpoint, asset structure, semantic role, reading path and image-text integration. Image, color, filter or day/night changes alone are blocked. Locale resolves from current Operator instruction, Project region and Audience context; one question is allowed only when missing region materially changes the scene.

## Thresholds and approval

Lead-generation calibration requires Click Clarity 85, Semantic Relevance 80, Painpoint–Scene Congruence 85, Image Quality 85 and Candidate Set Visual Diversity 85; Typography Spatial Integrity, Typography Breathing Room, Thumbnail QA and actual-pixel inspection must pass and hard blocks must be zero. Passing never selects a candidate or grants G4/G5.

## Isolation

Commercial-space constraints such as area, same-space sequence, person bans, specific scenes, brand signature and pricing remain in the commercial Industry Pack, Overlay or Project Profile. They are explicitly excluded from the universal baseline.
