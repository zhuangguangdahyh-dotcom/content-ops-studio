# Style Lock production

Only Runtime may create `SLV-1`, and only after an APPROVE Review and matching G4 Approval Event. The lock binds CV, Copy Version, VV, FPV, first-page asset/checksum, Renderer environment and G4 identity.

It freezes canvas, VV-1 safe area, typography tokens and actual resolved fonts, colors, grid, image treatment, layout logic, brand/page-number rules and permitted variations. It contains no PNG bytes, font files, browser paths, HTML, CSS, secrets or user Home paths.

After creation, the allowlisted Feishu state becomes first-page approved and records the Style Lock Version. Read-after-write and replay are mandatory. Style Lock makes pages 2–6 eligible but does not generate them.

The formal structure is `locked_rules`, `allowed_variations` and `prohibited_deviations`. It locks visual language, identity, type/palette/image treatment, grid and responsibilities, while allowing page subject, composition, crop, text position, whitespace and local emphasis to vary. It must not duplicate the cover layout mechanically.
