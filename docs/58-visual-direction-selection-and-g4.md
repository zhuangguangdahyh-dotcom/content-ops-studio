# Visual direction selection and G4

COLD_START projects receive two or three materially different real previews; LEARNING projects receive one or two. Mature compatible Profiles and explicit current directions may skip exploration. Candidates expose composition, subject, channel, mode, palette, typography character and quality; recolors or font swaps of one template are rejected. Candidate letters never reserve fixed AI/Pure Typography/Mixed slots: directions come from the current Dynamic Visual Strategy and may share a channel when their actual visual arguments differ.

Candidates are not First Page Versions and do not trigger G4, Style Lock, formal delivery or Feishu visual writes. The Operator selects one current Candidate ID. A later Visual Plan revision and formal cover are separate operations. G4 then judges mechanical quality, visual quality and project fit. Only explicit checksum-bound approval can create Style Lock.

Direction comparison must be fair at the complete-preview level. When an initial Candidate asset does not let the Operator judge final composition, typography character, copy density and mobile readability together, retain the original Candidate ID, asset, checksum and historical quality report and create a separate comparison artifact. Every complete preview uses the same approved copy, Renderer-owned text, the original direction language and a 1242×1660 canvas. Re-score the complete preview instead of reusing a background score. A contact sheet scales all candidates equally and places Candidate labels outside the candidate frames. This supplement remains a Direction Candidate Preview and does not create a Visual Plan revision, First Page Version or G4 event.

An explicit selection creates a separate Visual Direction Selection Artifact, then a new Visual Plan version and one formal First Page Version. The selection's feedback scope does not automatically expand: `PRODUCTION_FEEDBACK / CURRENT_SET` creates no Project Profile, Industry Pack or Global Preference rule. Formal production may refine semantic execution without mechanically copying Candidate coordinates. After mechanical, visual and project-fit QA, the workflow stops at G4; the Style Lock and remaining pages still require a checksum-bound Operator `APPROVE`.
