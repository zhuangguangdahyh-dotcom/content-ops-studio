# First-page revision

`RENDER_ONLY` creates the next FPV with the same CV, Copy and VV, then rerenders and requests a new G4. It may adjust layout, type scale within the approved system, color application or graphic composition without changing copy.

`PAGE_VISUAL_PLAN` and `GLOBAL_VISUAL_PLAN` return to the Phase 4A revision flow and require a new VV before rendering. `CONTENT_COPY` returns `CONTENT_REVISION_REQUIRED` to Phase 3B. Phase 4B never edits approved copy or mutates VV-1.

Every revision preserves the prior PNG, Manifest, Render Report, QA, Review and Approval history. Deletion is not a recovery or revision mechanism.
