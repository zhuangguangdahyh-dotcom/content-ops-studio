# Visual Plan revision

Visual-only changes increment `VV-N`, preserve the prior plan and do not change Content/Copy versions or require a new G3. Scope can address direction, mode, color, typography, layout, page plan, asset strategy, Text Layers or a full visual replan.

Copy or page-count changes require Content Revision and new G3. Phase 4A has neither produced Cover nor G4, so dry-run revision sets first-page regeneration and new-G4 requirements false and performs no write.
