# Multi-channel asset routing

The channels are Project Asset, AI Generated Visual, Programmatic Graphic, Evidence Asset, Pure Typography and Mixed Asset. They record provenance and responsibility; Visual Mode records the set's expression, so the two concepts are many-to-many.

Routing precedence is safety/authenticity/authorization, current Operator request, active Style Lock, confirmed Project Visual Profile, confirmed global preference, content evidence need, Industry Pack/overlay, Visual Mode, then Generic. Evidence outranks style. Precise structure uses Programmatic Graphic. Host ImageGen absence may route to a legitimate non-generated channel but never Mock.
