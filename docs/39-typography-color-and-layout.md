# Typography, color and layout system

Use 1242×1660, 3:4 portrait, an explicit Safe Area and a portable Chinese sans-serif stack. Typography tokens cover display/page title, body, supporting, number, caption and page number; every token ID is unique and every Text Layer resolves. Color tokens are unique and contrast-feasible.

The sandbox direction is warm white, charcoal and low-saturation blue-gray with high whitespace and page-specific diagrams. High-saturation red, excessive gold, generic business templates, unreadable small type and copy embedded in generated backgrounds are forbidden.
