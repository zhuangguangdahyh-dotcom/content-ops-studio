## Quality-gate design

Mechanical Geometry uses real Playwright output: `getBoundingClientRect`, computed font family/size/weight/line-height/letter-spacing, text and container boxes, z-index and visibility. Visual Spatial QA remains an independent required decision because lack of mathematical overlap is not visual proof.

Any formal text overlap, graphic occlusion, visual region collision, insufficient container padding, line/glyph collision, forced tracking, orphan character, competing primary text or density-forced compression blocks before Visual Quality scoring. Image/text interlock is allowed only when glyph integrity and readability remain intact.

Breathing Room uses ratios derived from actual font and line-height metrics. The 0.5–1.0 title-line-height title-to-secondary range is guidance, not a fixed-pixel template. When valid type cannot fit, the recovery order yields Cover Copy Revision or Page Composition Revision instead of silently compressing typography.
