# First-Page Production Handoff

The handoff is the next phase's only Cover-production input. It binds current Content/Copy/Visual versions, exact Cover copy/hash, canvas, Safe Area, grid, typography/colors, page plan, asset requirement, Text Layers, image treatment, capabilities and negative constraints.

It is readiness evidence, not a generated Cover. It contains no PNG/path, G4, Style Lock, Render Report or attachment. The next phase must produce page 1, request explicit G4 and only then create Style Lock; it may not reinterpret copy or direction.

# Phase 4B implementation

The Handoff now has a real consumer: the Production Renderer compiles its three exact Text Layers, 1242×1660 canvas, T96/R84/B96/L84 safe area and `PROGRAMMATIC_GRAPHIC` strategy. Browser-measured evidence is required before G4; the Handoff itself remains unchanged.
