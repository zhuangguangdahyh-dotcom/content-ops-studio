# ADR-0054: Universal image-set continuity and page-duty evidence

## Status

Accepted — 2026-08-27.

## Context

The retained C-9001 calibration set used one checksum-verified raster master for all inner pages and changed crops, overlays and Renderer compositions. That protected space identity but produced weak visual extension and repetitive backgrounds. Its former Group QA could report consistency and composition difference without proving that the set used materially different visual assets or fulfilled distinct page responsibilities.

The Operator supplied a mature commercial-space image-post workflow as evidence. Only its cross-industry principles are transferable: one set-level visual motif, same-world continuity, distinct page duties, materially different backgrounds and viewpoints, unified typography/color/grid logic, mobile readability and a useful closing page. Commercial-renovation scenes, area, customer type, brand signature, price restrictions and industry bans are not transferable Universal rules.

## Decision

1. A formal full set requires an `Image Set Production Strategy` before remaining-page production and an `Image Set Continuity Report` before G5.
2. Page duties are industry-neutral: page 1 is `COVER_CLICK`; middle pages are `VALUE_DELIVERY`; the last page is `SUMMARY_CONVERSION`.
3. One visual motif and one visual-system key bind the set. Each page retains at least two declared continuity anchors.
4. Image-dependent pages normally declare `DISTINCT_BACKGROUND_REQUIRED`. Duplicate source checksums fail even when crops, overlays, exposure, typography or layouts differ.
5. Raster pages require materially different shot signatures. Same-axis or near-identical views fail.
6. Evidence reuse is permitted only through explicit `REUSE_WITH_MATERIAL_TRANSFORMATION`; Pure Typography and precise Programmatic Graphic pages use `NO_RASTER_BACKGROUND`.
7. Every page has a unique semantic responsibility and explicit difference from the previous page. A closing page must provide useful resolution before conversion language.
8. Hard blocks cannot be compensated by aggregate scores. A pass remains pending explicit Operator G5 approval.
9. Historical files, checksums and reports remain immutable. The C-9001 set is retained as technical evidence and reassessed as not meeting the new full-set continuity gate; it is not regenerated by this decision.

## Consequences

The system now distinguishes `same visual world` from `same source image`. Future scene/editorial full sets need enough coherent source assets before Renderer production begins. When those assets cannot be verified, the run blocks instead of repeating a master or fabricating identity. Industry Packs may add stricter scene-specific rules but cannot weaken the Universal continuity and page-duty gates.
