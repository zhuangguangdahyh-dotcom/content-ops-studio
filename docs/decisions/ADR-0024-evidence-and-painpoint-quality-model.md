# ADR-0024: Evidence and painpoint quality model

Status: Accepted  
Date: 2026-08-24

This is the canonical filename for ADR-0024. The decision is recorded in [ADR-0024-research-evidence-and-quality.md](./ADR-0024-research-evidence-and-quality.md): painpoints retain A/B/C/D evidence, deterministic weighted scores, honest lower counts, bounded excerpts, and strict D-grade restrictions. The implementation does not claim semantic embedding deduplication; it performs deterministic identity, normalized-text, source-location, and content-hash checks.
