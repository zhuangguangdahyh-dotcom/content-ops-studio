# ADR-0045: Universal visual fallback and spatial QA

- Status: Accepted
- Date: 2026-08-26

## Context

The visual pipeline could satisfy mechanical and semantic checks while converging on repeated photo-plus-title layouts. Cold-start typography also lacked a governed, verifiable fallback.

## Decision

Adopt `UVDPV-1` and `TDPV-1` as lowest-priority fallback policies. Keep them separate from Industry Packs and Project learning. Add strict reports for editorial spatial composition, image-text integration, candidate-set diversity, Painpoint-scene congruence and locale fit. Extend Dynamic Visual Strategy and Project Visual Profile additively. Require actual Renderer font evidence and preserve Operator approval as the final aesthetic boundary.

## Consequences

- A universal preference cannot override current, Project, brand, content, industry or platform rules.
- Songti is a fallback preference, not a forced cross-project font.
- Candidate sets need materially different production logic, not cosmetic variants.
- Category relevance cannot substitute for Painpoint evidence.
- Scores remain evidence and never select a direction.
- Commercial-space rules remain isolated.
