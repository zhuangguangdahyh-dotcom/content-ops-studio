# Image Production Specification V1

Phase 4B-R formalizes eight modules: multi-channel asset routing; formal text and Renderer responsibility; quantity and batches; visual-direction selection before G4; five-layer single-image quality; group consistency and difference; Industry Visual Packs plus Project Visual Profiles; and explicit feedback-to-rule learning. Phase 4B-R.1 adds a deterministic Dynamic Visual Strategy Synthesizer before routing and production.

The architecture is Universal Production Core + versioned Industry Visual Pack + versioned Project Visual Profile + Per-Content Dynamic Visual Strategy/Visual Plan. The Synthesizer combines Project, Subject, Audience, platform, industry priors, overlays, confirmed project/global rules, current painpoint/content/page roles, authorized assets/references, gate/feedback history, current Operator instructions and production constraints. Industry Pack and Visual Mode are inputs, not finished styles. Candidate assets, formal assets, attempts and failures are counted separately. Production writes only to Project Home through controlled Runtime paths and never falls back to Mock.

The Synthesizer emits per-page channel, mode, subject, composition, realism, color, typography, text region/ratio, effects, quantity, batches, thresholds, risks, confidence, ambiguities and reasons. Maturity drives exploration: COLD_START 2–3, LEARNING 1–2, MATURE one formal first-page direction, and REVIEW_REQUIRED blocks reuse.

Historic `C-0001` artifacts remain immutable. Its earlier candidate set, VV-1 and FPV-1 are preserved; a later explicit Operator turn selected A and created VV-2/FPV-2. Phase 4B-R.1 does not touch or advance that G4-pending run.
