# Phase 2B provisioning and recovery matrix

| Failure/interruption                                    | Detection                                                       | Automatic action                                             | Operator-visible result                                | Destructive action |
| ------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------ | ------------------ |
| Authentication failure                                  | validated token envelope or HTTP auth code                      | stop; no provisioning write                                  | `FEISHU_AUTH_FAILED` / `FEISHU_TOKEN_INVALID`          | none               |
| Permission insufficient                                 | HTTP 403 or documented missing scope                            | no retry                                                     | `FEISHU_PERMISSION_DENIED` / missing-scope diagnostic  | none               |
| Base create returns, local save fails                   | pre-request create-intent remains without app token             | block all further creates                                    | `FEISHU_ORPHAN_WORKSPACE`; reconcile manually          | none               |
| Ambiguous same-title candidates                         | recovery candidate scan has more than one match                 | block                                                        | `FEISHU_DUPLICATE_WORKSPACE_CANDIDATES`                | none               |
| Single unverifiable orphan candidate                    | title matches but project identity cannot be established        | block                                                        | `FEISHU_ORPHAN_WORKSPACE`                              | none               |
| Default table conflict                                  | default ID absent, not unique, or non-blank structure ambiguous | block                                                        | schema/orphan diagnostic                               | none               |
| Partial table creation                                  | next resume lists tables and resolves by deterministic name     | adopt verified tables; create only missing tables            | resumed phase/checkpoint evidence                      | none               |
| Partial non-relation field creation                     | state plus remote field listing                                 | map verified IDs; create only missing fields                 | resumed field operations                               | none               |
| Relation failure                                        | relation type/target validation or transport error              | stop; later resume only after all table IDs resolve          | `FEISHU_RELATION_CONFLICT` or redacted transport error | none               |
| View creation failure                                   | list/read verification                                          | add missing named view on authorized repair                  | `REPAIR_AVAILABLE` or transport error                  | none               |
| Project record written before verification interruption | unique-key Search Records                                       | adopt exactly one matching record and read verify            | replay reports verified record                         | none               |
| Record unique-key duplicates                            | search returns more than one                                    | block                                                        | `FEISHU_RECORD_CONFLICT`                               | none               |
| Batch partial/unverified response                       | response count and per-record read verification                 | retry only the unverified item; preserve verified items      | per-item success/failure result                        | none               |
| HTTP 429                                                | status and `Retry-After`                                        | bounded delay/retry and redacted retry log                   | `FEISHU_RATE_LIMITED` if exhausted                     | none               |
| 408/network/5xx                                         | classifier, timeout, or fetch failure                           | bounded exponential backoff with jitter                      | timeout/API error if exhausted                         | none               |
| Active project lock                                     | lock manager ownership check                                    | reject concurrent writer                                     | lock conflict; original run remains authoritative      | none               |
| Stale lock                                              | Runtime stale-lock policy and owner evidence                    | only Runtime-approved recovery path                          | traceable stale-lock resolution                        | none               |
| Same run resumed twice                                  | project lock + state + idempotency scope                        | one writer; other blocks/reuses verified state               | deterministic replay outcome                           | none               |
| Same idempotency scope, changed input                   | deterministic fingerprint                                       | block                                                        | `FEISHU_RECORD_CONFLICT`                               | none               |
| Missing table/field/relation/view                       | reconciliation plan                                             | add-only repair when both write gates are present            | `REPAIR_AVAILABLE`, then verified                      | none               |
| Extra remote table/field/view                           | remote snapshot diff                                            | preserve and report                                          | extra-object inventory                                 | none               |
| Field type drift                                        | stable field ID/type comparison                                 | no automatic update                                          | BLOCKED and manual decision required                   | none               |
| User-renamed field                                      | stable field ID resolves current name                           | refresh name snapshot/mapping                                | `UPDATE_MAPPING`; future writes use current name       | none               |
| G1 not approved                                         | provisioning status                                             | pause                                                        | `AWAITING_APPROVAL`, gate `G1 PROJECT_PROFILE`         | none               |
| G1 approved                                             | explicit approval plus mapped project record                    | update status fields, read verify workspace, persist success | project active                                         | none               |
