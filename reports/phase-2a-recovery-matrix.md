# Phase 2A Recovery Matrix

| Failure point                             | Detected by                     | Existing side effect           | Idempotency decision       | Recovery action                        | Re-executed work             | Preserved artifacts           | Expected status            |
| ----------------------------------------- | ------------------------------- | ------------------------------ | -------------------------- | -------------------------------------- | ---------------------------- | ----------------------------- | -------------------------- |
| Step started, no completion               | Journal cursor                  | none or unverified             | not successful             | retry that step                        | failed/current only          | prior Journal                 | `RUN_RESUMING`             |
| Side effect succeeded before verification | Write Log plus state read       | target may exist               | read before retry          | verify existing state, then mark       | only missing/unverified      | target and attempts           | running or blocked         |
| Write Log verified before checkpoint      | Journal/Write Log vs checkpoint | verified write                 | never repeat               | rebuild checkpoint from Journal        | none for verified step       | write history                 | `RUN_RESUMING`             |
| Checkpoint written before approval        | pending approval snapshot       | no new approval                | wait                       | resume only on exact approval          | post-gate steps only         | all pre-gate artifacts        | `AWAITING_APPROVAL`        |
| Approval appended before resume           | approvals and Journal           | approval exists                | same ID/content replays    | append/resume idempotently             | post-gate steps only         | approval history              | `RUN_RESUMING`             |
| Checkpoint invalid, Journal intact        | head/hash comparison            | history intact                 | Journal is authority       | rebuild checkpoint                     | none already verified        | Journal and old file evidence | recoverable                |
| JSONL partial tail                        | JSONL newline check             | uncertain last event           | unsafe                     | block and diagnose                     | none                         | entire Run directory          | `RUN_BLOCKED`              |
| Journal hash chain altered                | event-chain verifier            | evidence untrusted             | unsafe                     | block and diagnose                     | none                         | entire Run directory          | `RUN_BLOCKED`              |
| Stale project lock                        | lease inspection                | previous owner record          | explicit recovery only     | archive lock with reason, append event | current incomplete step only | lock history                  | recoverable                |
| Active foreign lock                       | exclusive create/owner check    | other writer active            | conflict                   | do not delete or steal                 | none                         | foreign lock                  | `RUN_CONFLICT`             |
| Mock batch third item fails               | batch result and read-back      | first, second, fourth verified | successes replay           | retry failed key only                  | third item only              | successful Mock records       | success after retry        |
| Asset fixture missing                     | filesystem preflight            | none                           | invalid input              | block before G4                        | none                         | request evidence              | failed/blocked             |
| Pack content changes on resume            | snapshot hash drift             | earlier artifacts exist        | historical snapshot wins   | block or require explicit new Run      | none silently                | snapshot/artifacts            | conflict/blocked           |
| Same Run resumed twice                    | pending approval and Run Plan   | first resume may finish        | completed result immutable | return conflict/status                 | none                         | completed run                 | conflict or success replay |

Recovery never deletes a Run directory, approved artifact, Journal entry, approval, or write attempt as rollback.
