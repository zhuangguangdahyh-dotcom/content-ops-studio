| Tool                                | Goal                                                            | Main input/output                                       | Annotation       | Runtime/write scope                          | Stable failures                                      | Live evidence             |
| ----------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------- | ---------------- | -------------------------------------------- | ---------------------------------------------------- | ------------------------- |

| `content_ops_plan_content_creation` | Produce plan and angle decision                                 | operation/problem/page count → plan/angle/hash          | read-only        | none                                         | insufficient angles, invalid pages                   | PASSED                    |

| `content_ops_finalize_content_copy` | Duplicate/quality gate and one-row Feishu finalize              | artifact hashes/idempotency/confirmation → G3 request   | open-world write | one Content row plus primary Painpoint state | duplicate, quality block, live gate, write conflict  | PASSED                    |
