# Phase 4B-R.2 Cover Tool Catalog

Six narrow tools were added to the bundled local MCP surface:

- `content_ops_plan_cover_conversion`
- `content_ops_submit_cover_copy_revision`
- `content_ops_evaluate_cover_thumbnail`
- `content_ops_evaluate_cover_click_clarity`
- `content_ops_evaluate_visual_semantic_relevance`
- `content_ops_get_cover_concept_candidates`

The complete MCP catalog contains 67 tools; 20 are Image Production/Cover tools. Inputs and outputs remain strict, JSON structured and bounded to user-goal operations. No tool adds generic shell, arbitrary fetch, raw Feishu API, delete, publish or unrestricted filesystem authority.

Planning and evaluation tools are non-writing. Revision submission uses existing Runtime evidence and state validation. Candidate retrieval cannot select a candidate, create a formal FPV, approve G4 or create a Style Lock.
