| Stage                     | Input artifacts                                                                 | Output artifacts                                                    | Required versions                                           | Required approval                 | Owner                   | Blocking conditions                                                                                              | Invalidation conditions                                                               |
| ------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------- | --------------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Visual Planning           | Approved Content Package, active project rules, platform/industry packs         | Visual System, Page Visual Plans                                    | Current content, copy, new visual plan                      | G3 `CONTENT_COPY` already active  | `visual-planning`       | Copy not current; page count/sequence/token errors; unsafe overflow strategy                                     | Page copy/count or global visual change                                               |
| First Page Generation     | Page 1 Visual Plan, references, constraints                                     | First-page Generation Manifest; eventual background Asset Reference | Current content/copy/visual plan; no Style Lock required    | None beyond current G3            | `image-set-production`  | Page 1 missing/not cover; unsafe path; Adapter unavailable; secret-bearing request                               | Page copy/count/global visual change or first-page regeneration                       |

| Style Lock Creation       | Visual System, first-page plan/asset, G4 event                                  | Style Lock                                                          | Current content/copy/visual plan and new Style Lock version | Active matching G4                | `image-set-production`  | Missing/stale/deprecated/wrong-target G4; secret/path violation                                                  | Page copy/count or global visual change                                               |
| Remaining Page Generation | Page Plans 2..N, Style Lock, references                                         | Generation Manifests and background assets                          | Current content/copy/visual plan/Style Lock                 | Current G4 embodied by Style Lock | `image-set-production`  | Missing Style Lock; version/target mismatch; attempt/reference/path/checksum error                               | Page copy/count/global visual change; local page regeneration affects page dependents |
| Rendering                 | Page Plan, Style Lock, background asset, text layers, canvas/safe area          | Render Report; eventual rendered page asset                         | Current visual plan/Style Lock and referenced generation    | Current G4 through Style Lock     | `content-finalization`  | Overflow, clipping, missing asset/output/checksum, wrong canvas/page, unsafe region/path, blocking font fallback | Upstream generation, layout, copy, global visual, or file change                      |
| QA                        | Current content, plans, Style Lock, Generation Manifests, Render Reports/assets | QA Report with Content/Visual/File/Data layers                      | All current versions and assets                             | None                              | `content-finalization`  | Missing category; failed BLOCKING check; stale asset/version; statistics mismatch                                | Any relevant content, visual, generation, render, or file change                      |
| Final Approval            | Complete current set and ready QA                                               | G5 Approval Event                                                   | Current final-set target version                            | Explicit G5 `FINAL_SET`           | `content-studio-router` | QA not ready; blocking count nonzero; incomplete/unsafe assets; wrong target/version                             | Any new content/visual/asset/render/QA version                                        |
| Final Manifest            | Current QA, G5, assets, content/visual/style/manifests/reports                  | Immutable Final Manifest and new version directory                  | Current content/copy/visual plan/Style Lock/assets          | Active matching G5                | `content-finalization`  | Stale/deprecated G5; old/failed QA; missing page/ref/checksum; unsafe path; count mismatch                       | Any upstream or final-file replacement; history retained                              |
| Synchronization           | Existing Final Manifest and external workspace state                            | Independent sync status/log                                         | Final Manifest version; external record version             | No new visual approval            | `content-finalization`  | Capability/permission/conflict/write/read-verification failure                                                   | Retry only failed sync side effect; Final Manifest and image success remain intact    |
